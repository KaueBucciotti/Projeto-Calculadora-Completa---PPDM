# 🧮 Calculadora Android - Kotlin

Uma aplicação de calculadora funcional desenvolvida para Android, focada no aprendizado de layouts modernos, manipulação de eventos e integração com ferramentas de desenvolvimento profissional.

## 🚀 Funcionalidades

- **Operações Básicas**: Soma, Subtração, Multiplicação e Divisão.
- **Operações Avançadas**: Cálculo de Potenciação (`^`).
- **Interface Moderna**: Design "Dark Mode" com botões estilizados.
- **Layout Adaptável**: Uso de `GridLayout` para organização precisa dos componentes.
- **View Binding**: Implementação eficiente para interação com os elementos da interface.

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: [Kotlin](https://kotlinlang.org/)
- **IDE**: Android Studio (Ladybug/Electric Eel+)
- **Layout**: XML (ConstraintLayout & GridLayout)
- **Versão do SDK**: Compile SDK 36 / Target SDK 36
- **Controle de Versão**: Git & GitHub

## 📐 Conceitos Aplicados

Durante o desenvolvimento deste projeto, foram aplicados os seguintes conceitos de Engenharia de Software e Desenvolvimento Android:

* **View Binding**: Substituição do antigo `findViewById` por uma forma segura e eficiente de acessar componentes.
* **Gerenciamento de Dependências**: Configuração do arquivo `build.gradle.kts` e sincronização de bibliotecas AAR.
* **CI/CD Básico**: Fluxo de trabalho com Git (add, commit, push) via terminal integrado.
* **Resolução de Conflitos de SDK**: Ajuste de metadados de compilação para compatibilidade com bibliotecas modernas da Google.
